# 🚀 ServiceNow Order Management Application

A custom ServiceNow application designed to automate the order management process for AI-powered safety devices used in construction environments.

## 📌 Problem Statement

Nuflam Technology manufactures AI-powered safety devices such as:
- AR Glasses  
- Safety Drones  
- Smart Hats  
- Environmental Sensors  

Their order process was completely manual:
- Orders via calls & emails  
- Tracking through spreadsheets  
- Email-based approvals  
- No centralized visibility  

This led to delays, errors, and inefficiency.

## 💡 Solution

Developed a custom ServiceNow application to automate the complete order lifecycle:

**Request → Approval → Dispatch → Delivery Tracking**

## ⚙️ Features

- 🛒 Service Catalog for ordering devices  
- 🔄 Automated approvals using Flow Designer  
- 🧠 Dynamic forms (Client Scripts & UI Policies)  
- 💰 Auto calculation of total order amount  
- 🔐 Role-Based Access Control (ACLs)  
- 📧 Automated email notifications  
- ⏰ Scheduled jobs for delivery failure reminders  
- 📊 Reports & dashboards for insights  

## 🔁 Workflow

1. Client Request  
2. Device Management Review  
3. Release Team Approval  
4. Dispatch Management  
5. Delivery Confirmation  

## 📈 Impact

- Reduced manual effort  
- Faster approvals  
- Improved tracking  
- Better operational efficiency  

## 🛠️ Technologies Used

- ServiceNow Studio  
- Flow Designer  
- Service Catalog  
- Client Scripts  
- UI Policies  
- ACL & Roles  
- Notifications  
- Scheduled Jobs  
- Git Integration
